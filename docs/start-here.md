# Start here

[Home and situation index](../README.md#choose-your-situation) · [Toolkit](toolkit.md) · [Validation](lab-validation.md)

Use the home index to select the procedure for the observation in front of you. The short procedures contain decisions and interpreted examples; [the archive](reference/commands.md) contains older command variants. Synthetic output is labeled; only the [validation record](lab-validation.md) describes executed exercises.

## Set up once

1. Prepare the [toolkit](toolkit.md) and a private notebook outside this repository.
2. Rehearse one [local HTTP comparison](lab-validation.md#executed-record-http-truefalse-controls), then a target-lab procedure relevant to your next practice.
3. Select [exam evidence](exam.md) or the [client engagement workflow](pentest.md), because their objectives and reporting differ.

## When working a target

Start with [discovery](methodology.md). Pick one question, preserve the request/command and a contrasting result, then record the next decision in the [machine template](../templates/machine.md). If a tool fails, use [troubleshooting](troubleshooting.md) to identify the failure layer before changing another variable.

An unfamiliar command is a prompt to read its prerequisite and installed help. Use the [technique template](../templates/technique.md) to turn a reproduced lab observation into a reusable procedure.
